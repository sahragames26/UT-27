# UT 27 — Ultimate Team Web Prototype

واجهة أولية للعبة UT 27 مبنية على Three.js وJavaScript، مع الحفاظ على نموذج مباراة 3D الأصلي.

## الملفات
- `index.html`: واجهة UT 27، الشاشات، القوائم، الباكات.
- `src/main.js`: واجهة التحكم والمنطق مع Three.js والجيمبلاي.
- `src/style.css`: تصميم الواجهة المتجاوب للموبايل والكمبيوتر.

## طريقة تركيب الملفات
استبدل الملفات القديمة بهذه النسخ:
1. `ut27_index.html` أعد تسميته إلى `index.html` وضعه في جذر المشروع.
2. `ut27_main.js` أعد تسميته إلى `main.js` وضعه داخل مجلد `src`.
3. `ut27_style.css` أعد تسميته إلى `style.css` وضعه داخل مجلد `src`.

احتفظ بنفس هيكل المجلدات. لا تضع ملفات `main.js` و`style.css` بجانب `index.html`؛ يجب أن يكونا داخل `src/`.

## التشغيل
لا تفتح `index.html` مباشرة من مدير الملفات. شغّل المشروع عبر خادم محلي:
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000`، أو ارفع مجلد المشروع كاملًا إلى GitHub ثم انشره عبر Vercel.

## التحكم
- L1 / R1: التنقل بين الأقسام الرئيسية عند توصيل يد تحكم متوافقة.
- L2: فتح/إغلاق القائمة السريعة.
- الأسهم أعلى/أسفل: التنقل في القائمة السريعة.
- X: اختيار العنصر.
- O: رجوع/إغلاق.
- بالكمبيوتر: PageUp / PageDown للتنقل، وEscape أو L لفتح القائمة السريعة.
- في المباراة: WASD أو الأسهم، J تمرير، K تسديد، Tab تبديل اللاعب.

## ملاحظات النسخة
- اللغة والاختيارات البسيطة تُحفظ محليًا في المتصفح.
- الباكات والعملات والمهام وSBC وسوق الانتقالات بيانات تجريبية محلية وليست متصلة بخادم أو ببيانات EA.
- FC Points تظهر بصفر ولا يوجد شحن أو دفع حقيقي.
- Division Rivals وUT Champions يظهران كـ «قريبًا». Squad Battles فقط متاح كنموذج مباراة ضد AI.
- مستويات الصعوبة تظهر في الواجهة؛ لم يتم بعد بناء سبعة مستويات AI مختلفة فعليًا في منطق المباراة.
- يلزم HTTPS أو localhost لاستخدام Gamepad API على أغلب المتصفحات.
